Chapter 01: Prompt Chaining — environment and run instructions

Setup

Run these commands from the repository root:

```bash
cd chapters/chapter_01
bash setup_venv.sh
```

Activate the environment:

```bash
source .venv/bin/activate
```

Install additional dependencies (if any):

```bash
pip install <package>
```

Notes

- The chapter `.venv` is kept inside `chapters/chapter_01/.venv` and is ignored by `.gitignore`.
