# Agentic Design Patterns

Agentic Design Patterns: A Hands-On Guide to Building Intelligent Systems by Antonio Gulli

This repository is a personal companion for notes, examples, and code while reading *Agentic Design Patterns*.

Repository layout

- chapters/: Markdown notes and writeups per chapter. Start from `chapters/chapter-template.md`.
- code/: small runnable examples organized per chapter.

Getting started

1. Create a branch for the chapter you are adding, e.g. `chapter_01`.
2. Copy `chapters/chapter-template.md` → `chapters/chapter_01/prompt-chaining.md` and fill it.
3. Add code examples under `code/chapter_01/` if needed.
4. Open a PR with a short summary and link to the chapter file.
