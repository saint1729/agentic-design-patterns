# Code — Chapter 05 (Tool Use)

Create the per-chapter venv and install dependencies:

```bash
cd code
./setup_venv.sh chapter_05
source chapter_05/.venv/bin/activate

# Copy example env and update secrets
cp code/.env.example code/chapter_05/.env
# edit code/chapter_05/.env with your secrets
```

Run examples from this folder. See `requirements.txt` for packages.
