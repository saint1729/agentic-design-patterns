# Code — Chapter 07 (Multi-Agent Collaboration)

Create a per-chapter virtualenv and install dependencies:

```bash
cd code
./setup_venv.sh chapter_07
source chapter_07/.venv/bin/activate

# Copy example env and update secrets
cp code/.env.example code/chapter_07/.env
# edit code/chapter_07/.env with your secrets
```

Put runnable examples and small agent simulations in this folder. Keep provider-specific integrations optional and documented in each example.
