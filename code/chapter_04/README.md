# Code — Chapter 04 (Reflection)

Create a per-chapter venv and install dependencies:

```bash
cd code
./setup_venv.sh chapter_04
source chapter_04/.venv/bin/activate

# Copy example env and update secrets
cp code/.env.example code/chapter_04/.env
# edit code/chapter_04/.env with your secrets
```

Run examples from this folder. See `requirements.txt` for packages.
