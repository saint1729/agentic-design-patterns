Chapter 02: Routing — code examples

This folder will contain runnable examples for the Routing pattern.

Setup (from repo root):

```bash
cd code
./setup_venv.sh chapter_02
source chapter_02/.venv/bin/activate

# Copy example env and update secrets
cp code/.env.example code/chapter_02/.env
# edit code/chapter_02/.env with your secrets
```

Add small, self-contained examples and include a `requirements.txt` when needed.
